# 🍽️ VIT Bhopal Mess Menu & Rating App

A Python desktop application that displays daily mess menus for VIT Bhopal catered messes and lets students rate and review meals.

## Features
* 📅 **Full Week Schedules**: View Breakfast, Lunch, Snacks, and Dinner for Mayuri, CRCL, and Rassense.
* 🌐 **Smart Scraper with Fallback**: Tries fetching live menus online, then seamlessly falls back to the embedded database if the site is down or unreachable.
* ⭐ **Rating & Feedback System**: Rate any meal (1 to 5 stars) and record notes saved locally.
* 📊 **Live Averages**: Instant calculation of average scores and review counts.
